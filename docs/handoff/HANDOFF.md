## What Nikola Is

Nikola is a **physics-first AGI architecture** — not a wrapper around a
language model, not a fine-tuned transformer, not a prompt-engineering stack.

The core thesis: cognition is what happens when wave interference patterns on a
Riemannian manifold are sampled, integrated, and fed back into themselves over
time. This is not metaphor. The physics model is implemented literally:

- A 9-dimensional toroidal wavefunction `Ψ` is maintained and propagated
  tick by tick using a Störmer–Verlet Strang-split symplectic integrator
- Input is injected as wave disturbances via a 9-emitter holographic array
  (emitters spaced at irrational π·φⁿ Hz intervals to prevent mode-locking)
- A Mamba-9D SSM and Neuroplastic Transformer (NPT) operate _on the wavefunction
  amplitudes directly_, not on token embeddings
- Output is generated by sampling the field via a Hilbert-curve scanner
  and projecting through a BERT-tiny decoder

The autonomy layer runs a real TD-learning dopamine loop, ATP+boredom
metabolism, and entropy-driven exploration — all feeding back into the
wavefunction injection rate.

This is the ATPM (Autonomous Toroidal Physics Model). See `ARCHITECTURE.md`.

## Why This Exists

Randy built Nikola alone. He had no co-founders, no team, no institutional
backing. The project is in an advanced but not yet complete state: the
physics engine works, the cognitive pipeline works, and all module stubs
have been implemented. What remains is integration, polish, and the Aria
language port.

The handoff package exists because:

1. No one else has ever worked in this codebase
2. The design decisions are unusual enough that a naive reader would
   discard or mis-implement things (particularly the ATPM physics and the
   irrational-ratio emitter spacing — these are **not arbitrary**)
3. Randy cares more about the project surviving than about credit

## Conditions of Transfer

If you are reading this as a formal handoff recipient:

1. **License terms apply.** The code is AGPL-3.0 with a commercial license
   available (see `LICENSE.md`). Do not strip attribution or re-license.

2. **Preserve the physics.** The most important constraint: do not simplify
   the ATPM to "just a transformer." The entire architecture depends on the
   integrity of the wave propagation model. See `ARCHITECTURE.md` and
   `GOTCHAS.md` §"Do not break these invariants."

3. **Do not discard the module registry.** The file
   `META/NITPICK/NIKOLA_PHASE_REGISTRY.md` (in the parent workspace, outside
   the git repo) is the authoritative record of every design decision made
   during implementation. If you gain access to it, treat it as primary
   documentation.

4. **The Aria language port is the long-term goal.** Nikola is ultimately
   intended to run in the Aria runtime, not C++. C++ is the bootstrap vehicle.
   Do not treat C++ as the permanent target.
